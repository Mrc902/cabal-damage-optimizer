# Cabal Online - Damage Optimizer & Simulator

An advanced damage optimization tool and simulator built with Python and **CustomTkinter**. Designed specifically for **Cabal Online** players to calculate marginal stat efficiency, test item upgrades, compare builds, and simulate active Battle Modes (BM2/BM3) and Aura.

## Features
- **Damage Calculation Panel:** Real-time damage calculations considering target defense, penetration, and critical limits.
- **Battle Modes & Aura Simulation:** Customizable buff toggles for BM2, BM3, and Arcana Aura.
- **Item Comparator:** Direct side-by-side comparison between two items to measure average hit gains.
- **Build Comparator:** Compare two complete character stat setups.
- **Stat Efficiency Diagnostic:** Marginal gain analysis showing percentage performance boosts per stat point.

## Requirements
- Python 3.9+
- `customtkinter`
